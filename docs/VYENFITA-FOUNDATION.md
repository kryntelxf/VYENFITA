# VYENFITA Foundation

## Project

VYENFITA is an AI-native business application and automation platform.

## Foundation

VYENFITA is based on the Appsmith Community Edition codebase.

## Development Branch

`vyenfita-development`

## Core Principles

- Preserve the stability of the upstream foundation.
- Keep proprietary VYENFITA code isolated from the core.
- Never disable tests to obtain a green CI result.
- Never claim verification without evidence.
- Prefer small, reversible changes.
- Design for production and horizontal scaling from the beginning.

## Product Direction

VYENFITA aims to provide:

1. AI-assisted application development
2. Business automation
3. Workflow orchestration
4. Business intelligence
5. Enterprise-ready security
6. Scalable deployment

## Engineering Rule

Every major change must pass CI before becoming part of the production branch.
