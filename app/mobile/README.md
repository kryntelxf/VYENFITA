# VYENFITA Mobile

React Native (Expo) mobile app for VYENFITA.

## Features

- 📱 Native iOS + Android
- 🔐 JWT auth + biometric (Face ID / fingerprint)
- 📊 Dashboard with real-time stats
- ⚡ Workflow monitoring
- ✅ Approve/reject from phone
- 🔔 Push notifications
- 🌓 Light/dark theme
- 📦 Offline-first with cache

## Prerequisites

- Node.js 18+
- Expo CLI: `npm install -g expo-cli`
- EAS CLI: `npm install -g eas-cli`
- iOS: Xcode 14+ (Mac)
- Android: Android Studio
