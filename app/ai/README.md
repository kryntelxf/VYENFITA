# VYENFITA AI Layer

AI-Native Business Application & Automation Platform

## Overview

VYENFITA AI Layer is the intelligence engine that powers application generation, workflow automation, and business intelligence capabilities.

## Features

- **Multi-Provider Support**: OpenAI, Anthropic, and extensible to any provider
- **Application Generation**: Build complete applications from natural language
- **Workflow Automation**: Generate automation workflows from descriptions
- **Security First**: API key authentication, rate limiting, audit logs
- **Provider Abstraction**: Switch providers without code changes
